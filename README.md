# Корпоративный фонд — демонстрационный сайт

Сайт на Django для студентов, партнёров и инвесторов. Включает страницы фонда, грантов, проектов, форумов, партнёров, документов, новостей и контактов. Интерфейс поддерживает русский, казахский и английский языки, светлую и тёмную темы.

## Запуск на Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте http://127.0.0.1:8000/.

Тексты грантов, контакты, партнёры, события и документы демонстрационные. Перед публикацией замените их подтверждённой информацией фонда.
